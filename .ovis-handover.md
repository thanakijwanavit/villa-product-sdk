## Goal
The deployed product Lambdas answer `{'body', 'statusCode', 'header': {}}` (README.md:44). `parseLambdaResponse` must parse that answer, plus API Gateway's `'headers'` and other proxy keys. It must not mutate the caller's dict, and it must work for every awsSchema allowed by settings.ini (>=0.0.13,<0.1).

Before the fix, `awsSchema.apigateway.Response.fromDict` passed every key to `cls(...)`. So `'header'`, `multiValueHeaders` and `isBase64Encoded` raised a TypeError, and every real answer became `ProductSdkError('could not be parsed')`.
